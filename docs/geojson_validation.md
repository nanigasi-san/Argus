# GeoJSON検証基準

Issue #102。ファイル読込、QR生成、QRから復元したGeoJSONには同じ `GeoJsonValidator` を適用する。`GeoModel.fromGeoJson` もこの結果を使う。GeoJSONのringは[GeoJSON仕様 RFC 7946 §3.1.6](https://www.rfc-editor.org/rfc/rfc7946.html#section-3.1.6)に従って解釈する。

## スマホ・QR・Garminの許容条件

![スマホ・QR・GarminのGeoJSON対応早見表](images/geojson_compatibility.png)

| 条件 | スマホ読込 | QR生成（AGZ1） | Garmin送信 |
| --- | --- | --- | --- |
| GeoJSON構造 | FeatureCollection内の単一Feature・単一Polygon | スマホと同じ | スマホと同じ |
| 外周 | 閉路・穴なし・自己交差なし・辺の重なりなし・正の面積 | スマホと同じ | スマホと同じ |
| 頂点数（閉路の終点を除く） | 3〜1,000点 | 3〜1,000点 | 3〜100点 |
| 座標 | 有限数の[経度, 緯度]。経度±180、緯度±90 | スマホと同じ | スマホと同じ |
| 数値変換後の形状 | ファイルの元座標、またはQR復元後の座標を検証 | 小数6桁へ丸めた復元後もスマホ用検証に合格 | 約1m単位のローカルXYに丸めた後も重複・自己交差・面積0がない |
| 容量・値域 | 1,000頂点超は交差判定前に拒否 | 単一QRの容量内（生成画面は2,500文字以内・誤り訂正Q）。1,000点以内でも容量超過は拒否 | ローカルXYが-32768〜32767、AGW1本体が2,048バイト以内 |
| 複数Feature・MultiPolygon・穴あり | 拒否 | 拒否 | 拒否 |
| 短い辺・小さい面積の警告 | 警告だけなら読込可能 | 復元後データの警告を表示し、形状が有効なら生成可能 | 元形状の警告だけでは拒否せず、量子化後の形状を別途検証 |

スマホとQRは共通の形状条件を使う。QR容量や丸めによる退化はQR生成固有の制限であり、元ファイルがスマホで読めてもQRを生成できない場合がある。Garmin非対応でもQRが有効ならスマホ向けのQRは生成できる。図の形状は模式図で、対応判定は上の表と下記の基準に従う。

## スマホで使える形状

| 判定 | 基準 |
| --- | --- |
| 入力形式 | `FeatureCollection` と `features` 配列。AGZ1と同じ単一Feature・単一Polygonのみ。複数FeatureとMultiPolygonは拒否する。 |
| ring | 各Polygonに外周ringを1本だけ許可。2本目以降は空でも穴として拒否。先頭点と末尾点が一致する閉路が必要。 |
| 頂点 | 閉路の末尾点を除いて異なる3頂点以上。連続重複点は拒否。外周頂点は1,000点まで（閉路の終点を除く）。超過時は交差判定の前に拒否する。 |
| 座標 | `[経度, 緯度]` の有限数。経度は-180〜180、緯度は-90〜90。高度など3要素目以降は使用しない。日付変更線をまたぐ辺は未対応。 |
| 交差と面積 | 非隣接辺の交差・端点接触・重なり、および隣接辺の折り返しを拒否。面積0も拒否。時計回り・反時計回りのみでは拒否しない。 |
| 警告 | 1m未満の辺、50km超の辺、100m²未満の面積。警告だけなら読込・QR生成は続行する。 |

エラーはコードと日本語の表示文を分離する。表示文には可能な範囲でFeature、Polygon、辺の位置と実測値・基準値を含める。エラーがあれば読み込み・QR生成を中止し、既存の監視範囲を置き換えない。

## QR生成

`agz1` ではスマホ用検証に加え、単一Feature・単一Polygon、元ファイル名、単一QRの容量を確認する。QRにもGeoJSON全体で最大1,000頂点の共通上限を適用する。Garmin固有の100頂点制限はQR生成には適用しない。座標を小数6桁へ丸めて復元したGeoJSONも同じスマホ用validatorで検証する。丸めで辺や面積が退化した場合はQR生成を中止する。生成画面のスマホ・Garmin対応判定と警告も、この復元後データに基づく。`gjz1` 復元後も共通validatorを使う。

## Garmin送信

スマホ用検証を通過した**元の形状情報**を `GarminCourseValidator` に渡す。AGW1生成前と送信直前に以下を確認し、合格した準備済み座標だけをエンコーダへ渡す。

| 判定 | 基準 |
| --- | --- |
| 形状 | 元データが単一Polygon。MultiPolygon由来の1個だけの形状も対象外。 |
| 頂点数 | 閉路の末尾点を除いて3〜100点。 |
| 量子化 | ローカルXYの各値がint16（-32768〜32767）以内。約1m単位へ丸めた後も連続重複・自己交差・面積0がない。 |
| データ | `AGW1|x,y;...` のASCII形式で2,048バイト以内。 |

Garmin非対応でもスマホ用の形状が有効なら、QR固有条件を満たす限りQRを生成できる。QR生成画面は利用できる端末とGarmin非対応の短い理由を表示し、辺ごとの警告・座標の数値・形式情報は「詳細」に折りたたむ。Garmin送信画面に非対応の理由を表示し、送信ボタンを無効化する。送信直前の検証にも失敗した場合は送信クライアントを呼ばない。

実際に通したGeoJSONの形と判定結果は[検証レポート](geojson_validation_report.md)にまとめる。
