# 審査メモ（0.8.2）

## 主な変更

- Android・iOSのリリース処理を改善しました。
- アプリの機能・権限・データ利用に変更はありません。

このリポジトリ内メモの用途説明を2026-09-29に訂正しました。App Store Connectに保存済みの文章を変更したことを意味しません。

## 確認事項

- ログインは不要です。
- 位置情報権限は、読み込んだGeoJSON競技エリアからの離脱を端末内で判定するために使用します。
- 通知権限は、競技エリアからの離脱警告を表示するために使用します。
- バックグラウンド位置情報は、ユーザーが開始した範囲監視を画面消灯中も継続するために使用します。
