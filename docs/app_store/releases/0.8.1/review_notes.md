ARGUSは、利用者が読み込んだGeoJSON競技エリアを監視するアプリです。今回の更新は配信処理の改善であり、アプリの監視機能、権限利用、審査用の操作手順に変更はありません。

利用者が明示的に監視を開始した後だけバックグラウンド位置情報を使用し、画面ロック中や他のアプリ使用中でもエリア外への離脱を検知します。位置情報は端末内でのみ処理し、開発者サーバーへ送信しません。サインインは不要です。

バックグラウンド音声は、エリア外を検知したときに警告音をループ再生するためだけに使用します。警告音はスヌーズ操作、安全エリアへの復帰、または監視終了で停止します。

警告音の確認手順:

1. 右上メニューから「設定」を開きます。
2. 「アラーム音量」の下にある「警告音をテスト」を押します。
3. iPhoneのホーム画面へ移動しても警告音が継続することを確認できます。
4. ARGUSへ戻り「テストを停止」を押すと停止します。

位置情報を拒否した場合、ARGUSは設定アプリを自動的に開きません。監視機能を使うために権限を変更するときだけ、利用者が権限カードの「アプリ設定を開く」を明示的に押します。
