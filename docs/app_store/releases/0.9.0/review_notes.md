# 審査メモ（0.9.0）

## 主な変更

- GeoJSONのファイル読み込み、QR生成・復元に共通の形状検証を追加しました。無効な座標、自己交差、穴を含む形状などを拒否し、理由を表示します。
- 保存済みのQR画像を写真ライブラリから選び、競技エリアと元のファイル名を復元できます。写真ライブラリへのアクセス説明を更新しました。
- GARMIN転送前に頂点数、座標値域、量子化後の形状を確認し、非対応データの送信を防ぎます。

## 確認事項

- サインインは不要です。
- 利用者が明示的に監視を開始した後、バックグラウンド位置情報を使って画面ロック中や他アプリ利用中もGeoJSON競技エリアからの離脱を検知します。位置情報の内外判定は端末内で行い、開発者サーバーへ送信しません。
- 通知権限は競技エリアからの離脱警告に使用します。
- バックグラウンド音声はエリア外警告のループ再生と、利用者が開始した警告音テストに使用します。警告はスヌーズ、エリア復帰、監視終了で停止します。
- 右上メニューの「設定」から「警告音をテスト」を押すと、通知やバイブレーションなしで音声を確認できます。ホーム画面でも継続し、アプリへ戻って「テストを停止」を押すと停止します。
- 位置情報権限を拒否しても設定アプリへ自動遷移しません。「アプリ設定を開く」を利用者が押した場合だけ移動します。
- カメラはQRスキャン、写真ライブラリはQR画像の選択と保存、BluetoothはGARMINとの転送・保存確認に使用します。
