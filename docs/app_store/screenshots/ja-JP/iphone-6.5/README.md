# App Store screenshots

App Store Connect の日本語ローカリゼーションに提出する、6.5インチiPhone向けスクリーンショットを保存します。

対応サイズ: `1242 x 2688` または `1284 x 2778` pixels

提出順:

1. `01-monitoring-setup.png` — 監視開始前の権限設定
2. `02-background-location-disclosure.png` — iOS専用のバックグラウンド位置情報説明（操作は「続ける」のみ）
3. `03-monitoring-settings.png` — iOS設定画面の「警告音をテスト」と監視パラメータ
