# リリースノート

利用者向けの変更点をまとめる。開発者向けの詳細は `docs/spec.md` を参照。

## 未リリース（監視安全性の強化）

`pubspec.yaml` のバージョンは `0.7.0+1009` のまま。配信時に上げる。

### ⚠️ 先に確認してほしいこと: GeoJSONの検証が厳しくなりました

**大会当日ではなく、事前に一度ファイルを読み込んで確認してください。**

安全エリアの一部が黙って無視されるのを防ぐため、GeoJSONの検証を厳格にしました。この結果、**これまで読み込めていたファイルが読み込めなくなる場合があります**。

| これまで | これから |
| --- | --- |
| 穴（内側のリング）は黙って無視して読み込んでいた | エラーになる。穴のないPolygonへ変換が必要 |
| 閉じていないリング（始点と終点が違う）は自動で閉じていた | エラーになる。始点と同じ座標を終点に追加が必要 |
| 3点のリングは自動で閉じて読み込んでいた | エラーになる。始点・終点を含む4点以上が必要 |
| `geometry` のないFeature、Polygon/MultiPolygon以外は黙って読み飛ばしていた | エラーになる |
| 連続する重複頂点は「自己交差」として弾いていた | 重複頂点として弾き、どの頂点かを表示する |

穴の無視は特に危険でした。湖や立入禁止区域を穴として書いていた場合、その内側が**安全エリアとして扱われていました**。

エラーメッセージには、どのFeature・どのPolygon・どの頂点が問題かと、実際の値が入ります。

```
Feature[0] のPolygon[0] の頂点[2]: 緯度が範囲外です（95.0）。
GeoJSONの座標順は[経度, 緯度]です。経度と入れ替わっていないか確認してください。
```

読み込めなくなった場合は、メッセージが示す箇所を修正するか、GISツールから穴なし・閉じたリングで書き出し直してください。

### 位置情報が正しく取得できないとき

- 端末から不正な座標（数値でない、範囲外）が届いた場合、その測位を使わずGPS途絶として扱います。以前はそのまま判定に使っていたため、**エリア外にいても警報が確定しない**状態が続くことがありました。
- GPS精度が悪い測位では、それまでに数えたエリア外の観測を破棄しません。以前は破棄していたため、木の下など精度が周期的に悪化する場所では**エリア外の確定に必要な時間に到達できず、警報が鳴らない**ことがありました。

### GPSが受信できなくなったときの動作

- GPSが途絶すると警告通知と振動を出し、位置情報サービスへ自動で再接続します。
- **警告は途絶が続くあいだ繰り返し出ます**（既定60秒間隔）。経過時間も表示します。以前は最初の1回だけでした。
- iOSではバックグラウンドでも通知音が鳴ります。以前は無音で、画面を見ていないと気づけませんでした。
- 位置情報の権限が失効している場合は、再接続をやめて権限の案内を表示します。以前は原因を示さず再試行を続けていました。
- 位置情報サービスの再開に繰り返し失敗した場合も、再試行をやめて確認を促します。アプリを開き直すと再試行します。
- 「再開はできているがGPSが受信できない」状態（トンネル・森林・屋内）では再試行をやめずに待ち続けます。

### エリア外警告の表示

- **エリア外（OUTER）の警告中は、GPSの状態表示で警告が上書きされなくなりました。** 以前はエリア外で警報が鳴っている最中にGPSが途絶すると、赤い「外側」が橙の「再接続中」に変わり、エリア外だと分からなくなっていました。GPSの状態は円の中の小さなバッジで併記します。
- GPS精度が悪いあいだは、最後に精度が良かった位置からの案内であることを明示します。低精度の測位で警告が解除されることはありません。

### 警報が鳴らない・止まらないときの通知

- 通知・警報音・バイブのいずれかを**発報できなかった場合に画面へ表示します**。以前はログにだけ残っていたため、警報音が鳴っていないのに気づけませんでした。
- 警報を**停止できなかった場合も表示します**。以前は停止済みとして扱っていたため、鳴り続けている理由が分かりませんでした。
- 1分ミュート（スヌーズ）は、実際に停止できた場合だけミュート状態になります。ミュート解除で警報を再開できなかった場合も表示します。
- アプリに戻ったときに警報を鳴らし直せなかった場合も表示します。
- これらの警告は**閉じるまで消えません**。数秒で消える表示では、走行中に画面を見たときには消えているためです。
- 監視を開始するときに鳴っている音（試聴音、前回止められなかった警報）を止めます。止められない場合は監視を開始しません。常時鳴っている音があると、本物のエリア外警報と区別できないためです。

### 設定

- 設定は**保存に成功した場合だけ反映されます**。以前は先に反映していたため、保存に失敗すると「反映に失敗しました」と表示されるのに動作中の値は変わっており、次回起動で元に戻っていました。
- 保存された設定が壊れて読み込めない場合、初期設定で起動したことを起動時に知らせます。以前は黙って初期値に戻っていました。

### 応答しない場合の保護

- 監視の停止・アプリ終了時に端末側が応答しない場合、5秒で待つのをやめて後始末を続けます。以前は応答を待ち続け、開始も停止も設定変更もできない状態になることがありました。

### 監視の開始条件

- Androidのアラーム音量の確認を監視の開始処理そのものに移しました。確認から開始までの間に音量を下げても検出します。
- アプリ内のアラーム音量の下限を 0% から 10% に変更しました。0% を保存していた場合は 10% に補正されます。

### 監視中の設定変更

- 監視中は設定・GeoJSON・QRを変更できません。停止してから変更してください。
- **開発者モードは監視中も切り替えられます。** 表示の切り替えだけで監視の挙動には影響しないため、GPSが不調なときにログと詳細を確認できます。

### その他

- イベントログの保持上限を20,000件にしました（超えた分は古いものから削除）。長時間の監視でメモリが増え続けるのを防ぎます。
- 監視中は「アプリを強制終了しないでください」の注意を表示します。画面ロックや他アプリの利用中は監視を続けますが、強制終了すると停止し、自動復元はしません。
